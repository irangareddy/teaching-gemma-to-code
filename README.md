# Teaching Gemma to Code

A handbook for turning Gemma 4 into a coding agent: my notes, code and scores from the [Google Gemma 4 Developer Agent competition](https://www.kaggle.com/competitions/gemma-4-developer-agent) on Kaggle, written while I learn.

- `book/` — the Quarto handbook: one chapter per concept, written as I go
- `agent/` — the agent I submit (`agent.yaml`, prompts, tools, skills)
- `eval/` — my local scoring loop and the experiment log

Read it: https://irangareddy.github.io/teaching-gemma-to-code/ (after the first publish)

Preview locally: `quarto preview book`
